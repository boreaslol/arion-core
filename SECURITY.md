# Security Policy

## Supported Versions

Security fixes are published for the latest `0.1.x` release.

## Reporting a Vulnerability

Please use GitHub's private vulnerability reporting form:

https://github.com/boreaslol/arion-core/security/advisories/new

Do not open a public issue for suspected credential exposure, private data,
remote code execution, or another vulnerability that could put users at risk.

Include the affected version, reproduction conditions, expected impact, and
the smallest evidence needed to validate the report. Do not include real
credentials, customer data, or production payloads.

We aim to acknowledge a report within seven days. A confirmed issue will be
handled through a private advisory, a fix, and a coordinated public release.
